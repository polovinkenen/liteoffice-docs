# ADR 0002: движок экспорта PDF

Статус: принято · Дата: 2026-11-18

## Контекст

WLite экспортирует ProseMirror-документ в PDF с постраничной вёрсткой: A4/Letter,
книжная и альбомная ориентация, поля, колонтитулы, нумерация страниц, таблицы с
объединениями, изображения, списки и инлайн-форматирование. Сборка идёт на macOS,
Windows и Linux, MSRV workspace — Rust 1.90. Шрифты должны быть встроены в приложение,
чтобы PDF одинаково выглядел на всех машинах и не зависел от системных шрифтов.

## Варианты

### `typst` + `typst-pdf` 0.15.1

- Самая свежая версия, активная разработка, PDF-бэкенд `krilla`.
- Требует Rust 1.92: пришлось бы поднять MSRV workspace и CI-тулчейн.
- API заметно меняется между минорными версиями.

### `typst` + `typst-pdf` 0.14.2

- Библиотечная интеграция без внешних процессов и платформенных бинарников.
- Требует Rust 1.89, укладывается в текущий MSRV 1.90.
- API стабилен в пределах пина: `World`, `compile::<PagedDocument>`,
  `typst_pdf::pdf`.
- Чистый Rust: `krilla`, `rustybuzz`, `ttf-parser`, без нативных библиотек.
- Минусы: большой граф зависимостей, заметный рост времени и размера сборки;
  нестабильность API между версиями требует ручного обновления пина.

### Sidecar-бинарник `typst`

- Код интеграции проще: записать `.typ`, запустить CLI, прочитать PDF.
- Нужны собранные бинарники под каждую целевую платформу (`externalBin`),
  их версионирование, упаковка в установщики и проверки в CI.
- Появляется внешний процесс, временные файлы и зависимость от файловой системы.
- Оставлен как fallback из плана на случай проблем со сборкой библиотеки.

## Решение

Используем **`typst` и `typst-pdf` версии `=0.14.2`** в отдельном крейте
`crates/export-pdf`. Версия пиннится точно.

## Последствия

- `export-pdf` изолирует Typst: снаружи — `render(&PmDoc, &PdfOptions, title)`,
  внутри — собственный `World`, виртуальные файлы изображений и встроенные шрифты.
- Компиляция детерминирована: `World::today()` возвращает `None`, источник и
  изображения подаются из памяти; тесты проверяют число страниц, MediaBox и текст.
- В бандл включены шрифты Liberation Serif/Sans/Mono (OFL-1.1) с файлом лицензии;
  шрифты редактора отображаются в ближайший Liberation, неизвестные попадают в
  `warnings`.
- Время и размер сборки растут. При обновлении Typst нужно вручную проверять API,
  число страниц, MediaBox и встраивание шрифтов на трёх ОС.
- Параметры экспорта (бумага, поля, ориентация, колонтитулы) хранятся в localStorage
  интерфейса, а не в `settings.json`; формат настроек ядра не меняется.
- Предпросмотр — это временный PDF в кэше приложения, который открывается системным
  просмотрщиком; встроенный просмотрщик остаётся вне объёма MVP.
