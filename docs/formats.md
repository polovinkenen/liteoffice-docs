# Форматы

Документ описывает, что WLite импортирует и экспортирует, какие узлы и атрибуты
поддерживаются, где происходят потери и какие лимиты применяются. Слои и потоки
описаны в [architecture.md](architecture.md), известные ограничения — в
[limitations.md](limitations.md).

## Матрица форматов

| Формат | Импорт | Экспорт | Основное |
|---|---|---|---|
| TXT | да | да | UTF-8, абзацы через пустую строку, одиночный перенос → `hardBreak`. |
| Markdown (GFM) | да | да | Заголовки, списки и task-списки, код, цитаты, ссылки, изображения, таблицы; разрыв страницы — `<!-- pagebreak -->`. |
| HTML | да | да | Whitelist тегов и атрибутов, санитизация, без загрузки внешних ресурсов. |
| RTF | да | да | Абзацы, runs, шрифты/размеры/цвета, выравнивание, списки, простые таблицы, растровые изображения, ссылки. |
| DOCX | да | да | Runs, заголовки, списки, таблицы со span, изображения, ссылки, разрыв страницы; zip-проверки. |
| PDF | — | да | Typst: A4/Letter, ориентация, поля, колонтитулы, нумерация страниц. |

Формат определяется по расширению (см. матрицу), иначе возвращается `unsupported_format`.

## Модель документа

Общие узлы: `doc`, `paragraph`, `heading`, `text`, `hardBreak`, `bulletList`,
`orderedList`, `listItem`, `taskList`, `taskItem`, `blockquote`, `codeBlock`,
`horizontalRule`, `table`, `tableRow`, `tableHeader`, `tableCell`, `image`,
`pageBreak`.

Основные атрибуты:

- абзац и заголовок: `textAlign`, `indent`, `lineHeight`, `spaceBefore`, `spaceAfter`;
  у заголовка дополнительно `level` (1–6);
- список: `start` у `orderedList`, `checked` у `taskItem`; код: `language`; ячейка:
  `colspan`, `rowspan`, `colwidth`; изображение: `src`, `alt`, `title`.

Марки: `bold`, `italic`, `underline`, `strike`, `code`, `link` (`href`, `target`,
`rel`, `class`), `textStyle` (`fontFamily`, `fontSize`, `color`), `highlight` (`color`).

## Детали по форматам

### TXT

- Импорт: нормализует `\r\n` и `\r`; абзацы разделяются пустой строкой, одиночные
  переносы внутри абзаца становятся `hardBreak`. Разметка и атрибуты не читаются.
- Экспорт: только текст. Заголовки, цитаты и блоки кода выводятся текстом; списки —
  маркерами `-`/`1.` с отступами; таблица — строки через ` | `; изображение — `alt`;
  `pageBreak` и `horizontalRule` — линией `---`.
- Потери: task-списки не получают маркеров `[ ]`/`[x]`, а границы пунктов теряются —
  элементы сливаются в одну строку; при наличии форматирования возвращается
  предупреждение «Формат TXT сохраняет только текст…». Разрыв страницы при повторном
  открытии не восстанавливается.

### Markdown

- Включены расширения GFM: таблицы, task-списки, зачёркивание, autolink.
- Импорт: заголовки, абзацы, цитаты, блоки кода с языком, обычные и task-списки,
  таблицы (ячейки без объединений), `horizontalRule`, изображения, ссылки, марки
  `bold`, `italic`, `strike`, `code`; `softBreak` становится пробелом, `lineBreak` —
  `hardBreak`.
- Разрыв страницы: HTML-блок ровно `<!-- pagebreak -->` превращается в `pageBreak`.
  Прочие HTML-блоки, встроенный HTML и сноски пропускаются с предупреждением.
- Экспорт: заголовки, обычные и task-списки (`- [ ]`/`- [x]`), таблицы, код,
  цитаты, ссылки, изображения, `pageBreak` маркером `<!-- pagebreak -->`.
- Деградации: выравнивание, отступы и интервалы абзацев не сохраняются; `textStyle`,
  `highlight` и `underline` теряются; объединённые ячейки выводятся обычными с
  предупреждением; неизвестные узлы и марки упрощаются. Небезопасные ссылки и
  изображения не записываются.
- Изображения: разрешены `asset:`, растровые `data:` (`image/png|jpeg|jpg|gif|webp`),
  а также `http`/`https` и относительные адреса — их пропускает общий `is_safe_link`.
  `asset:` перед записью разрешается в `data:`, поэтому Markdown с встроенными
  картинками может быть большим; внешние URL записываются как ссылки, а не как
  встроенные данные, и в файле их содержимого нет.

### HTML

- Импорт: ищет `body`, читает блочные и inline-теги из whitelist. Поддерживаются
  заголовки, абзацы, цитаты, списки, task-списки (`data-type="taskList"` /
  `data-type="taskItem"`, `data-checked`), таблицы с `colspan`/`rowspan`, блоки кода
  (`class="language-…"`), `hr`, разрыв страницы `<div data-page-break="true"></div>`,
  изображения, ссылки и марки.
- Стили: `text-align`, `margin-left` (em → `indent`), `line-height`, `margin-top` и
  `margin-bottom` (pt → `spaceBefore`/`spaceAfter`); для текста — `font-family`,
  `font-size`, `color`, `background-color`. Небезопасные CSS-значения отбрасываются.
- Удаляются вместе с содержимым `script`, `style`, `form`, `iframe`, `object`,
  `embed`, `svg`, `math`, `template`; неизвестный inline-тег сохраняет содержимое
  с предупреждением.
- Изображения: только `asset:` и `data:image/png|jpeg|jpg|gif|webp`; внешние и
  относительные источники не загружаются.
- Экспорт: полный документ `<!DOCTYPE html>` с `<head>` и `<body>`; сохраняет
  абзацные стили, марки, списки, task-списки, таблицы со span, изображения, ссылки,
  разрыв страницы и `hr`. Неизвестные узлы и марки дают предупреждения.

### RTF

- Декодирование: ANSI-кодировки по `\ansicpg` (включая cp1251), `\uNNNN?`.
- Импорт: абзацы, runs, шрифты, размеры, цвета, выравнивание, отступы (только левый
  `\li`; правый `\ri` и отступ первой строки `\fi` игнорируются), интервалы и
  межстрочный интервал, списки через list table, заголовки стилями, простые таблицы,
  ссылки через поле `HYPERLINK`, разрыв страницы `\page`, горизонтальная линия,
  изображения `png`/`jpeg`/`gif`.
- Пропускаются с предупреждением: колонтитулы, сноски, комментарии, объекты, фигуры,
  emf/wmf/metafile, служебные destinations. Объединённые ячейки не поддерживаются.
- Экспорт: абзацы и runs, шрифты/размеры/цвета, выравнивание и интервалы, списки
  list table, заголовки стилями, простые таблицы, изображения `\pict`, ссылки,
  `\page`, горизонтальная линия. Цитаты становятся обычными абзацами, блок кода —
  моноширинным текстом, task-списки — маркерами `[x]`/`[ ]`; объединённые ячейки
  упрощаются, подписи изображений не сохраняются.

### DOCX

- Импорт: `docx-rs`; runs, заголовки по стилю/`outlineLvl`, списки по numbering,
  таблицы с `gridSpan`/`vMerge`, изображения из media (`png`, `jpeg`, `gif`, `webp`),
  ссылки, разрывы страниц, табы и символы.
- Атрибуты абзаца: выравнивание, отступ, интервалы до/после и межстрочный интервал.
  Марки: `bold`, `italic`, `underline`, `strike`, `textStyle` (шрифт, размер, цвет),
  `highlight`.
- Пропускаются с предупреждением: колонтитулы, сноски, оглавление, поля и
  PAGE/NUMPAGES, элементы управления содержимым, рецензирование (вставки, удаления,
  перемещения), фигуры и текстовые поля, вложенные таблицы в ячейках, разрывы колонок.
  Одновременное объединение ячейки по строкам и столбцам упрощается.
- Экспорт: заголовки стилями, списки и task-списки через numbering, таблицы с
  `gridSpan`/`vMerge`, изображения как media, ссылки, разрыв страницы. Цитаты — обычные
  абзацы, блок кода — моноширинный текст. Небезопасные ссылки пропускаются, подписи
  изображений не сохраняются, одновременный rowspan+colspan упрощается.
- Защита архива: до 10 000 файлов, 200 МиБ распакованного объёма, 100 МиБ на файл,
  степень сжатия не выше 1000 для файлов от 1 МиБ.

### PDF

- Только экспорт. Typst-вёрстка: A4 или Letter, книжная/альбомная ориентация, поля,
  верхний/нижний колонтитулы, нумерация. В колонтитулах доступны `{page}` и `{pages}`.
- Поддерживаются абзацы с выравниванием, отступами и интервалами, заголовки, списки и
  task-списки, цитаты, блоки кода, таблицы со span, изображения `data:` (png/jpeg/gif/
  webp) шириной 100% полосы набора, марки, ссылки, `pageBreak`, `horizontalRule`.
- Неизвестные узлы и марки пропускаются с предупреждением. Внешние изображения не
  встраиваются; `asset:` без разрешения даёт предупреждение. Ссылки проверяются общим
  `formats-core::is_safe_link` — та же политика, что и в остальных форматах.
- Шрифты: Liberation Serif/Sans/Mono; неизвестное семейство заменяется на Liberation
  Serif, отсутствующие глифы Typst дают предупреждение.

## Политика ссылок

`formats-core::is_safe_link` применяется при импорте и экспорте Markdown, HTML, RTF и
DOCX (а также для изображений) и при экспорте ссылок в PDF:

- разрешены схемы `http`, `https`, `mailto`, `tel`, `asset`, относительные и пустые
  ссылки;
- `data:` разрешён только для растровых `image/png`, `image/jpeg`, `image/jpg`,
  `image/gif`, `image/webp`;
- блокируются `javascript:`, `vbscript:`, `file:`, `blob:`, `data:text/html`,
  `data:image/svg+xml` и прочие схемы;
- HTML-сущности декодируются до проверки (до пяти проходов), управляющие символы
  запрещены, форматные символы и пробелы в схеме игнорируются. Это закрывает обходы
  вида `java&tab;script:`, `&#x6a;avascript:` и `java\u{200B}script:`.

## Лимиты

| Что | Значение | Где |
|---|---|---|
| Глубина модели / Markdown / HTML | 256 | `docmodel`, `formats-markdown`, `formats-html` |
| Узлы модели / Markdown / HTML | 1 000 000 | `docmodel`, `formats-markdown`, `formats-html` |
| Читаемый файл | 50 МиБ | `app-core/src/files.rs` |
| Токены RTF | 10 000 000 | `formats-rtf/src/lexer.rs` |
| Узлы RTF | 1 000 000 | `formats-rtf/src/parser.rs` |
| Глубина групп RTF | 512 | `formats-rtf/src/parser.rs` |
| Изображение RTF | 15 МиБ | `formats-rtf/src/parser.rs` |
| Файлы в DOCX | 10 000 | `formats-docx/src/lib.rs` |
| Распакованный DOCX | 200 МиБ | `formats-docx/src/lib.rs` |
| Файл внутри DOCX | 100 МиБ | `formats-docx/src/lib.rs` |
| Сжатие DOCX | 1000 для файлов от 1 МиБ | `formats-docx/src/lib.rs` |
| Изображение в assets | 15 МиБ | `app-core/src/assets.rs` |

Память на разбор Markdown и HTML ограничена размером входа (файлы больше 50 МиБ не
читаются). Тест лексера RTF проверяет бюджет 300 МиБ для `Vec<Token>`.

## Golden, fuzz и производительность

Фикстуры: `tests/fixtures/html`, `tests/fixtures/rtf`, `tests/fixtures/docx`; рядом с
каждым исходником лежит эталон `.json`. Golden-тесты проверяют импорт, экспорт и
round-trip.

```bash
for crate in wlite-formats-html wlite-formats-rtf wlite-formats-docx; do
  cargo test -p "$crate" --test golden
  UPDATE_GOLDEN=1 cargo test -p "$crate" --test golden
done
```

Fuzz-таргеты: `markdown_import`, `html_import`, `rtf_import`, `txt_import`,
`docx_import` в `fuzz/`. Входные данные длиннее 1 МиБ пропускаются.

```bash
for target in markdown_import html_import rtf_import txt_import docx_import; do
  cargo +nightly fuzz run "$target" -- -max_total_time=60 -rss_limit_mb=2048
done
```

Бенчмарк импорта (~300 страниц) и `validate`:

```bash
cargo test -p wlite-formats --test perf -- --ignored --nocapture
WLITE_PERF_MAX_MS=3000 WLITE_PERF_MAX_MB=800 \
  cargo test -p wlite-formats --test perf -- --ignored --nocapture
```

Пороги: 2000 мс медианы и 500 МБ пикового прироста памяти; вебвью, ввод, IPC, экспорт и PDF не измеряются.
