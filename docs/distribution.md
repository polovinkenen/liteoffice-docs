# Дистрибуция

Приоритет платформ — macOS и Linux. Windows собирается, но не входит в активные
каналы распространения. Документ фиксирует текущее состояние и порядок работ, чтобы
не обещать пользователям больше, чем есть.

## Текущее состояние

- Собираются `.dmg` (macOS arm64), `.deb` и `.AppImage` (Linux x64), а также `.msi` и
  NSIS `.exe` для Windows.
- Сборки не подписаны: Apple Developer Program не оплачен, сертификата Windows нет.
  macOS-пользователь подтверждает запуск в системных настройках или снимает карантин
  вручную (см. [README](../README.md#установка)).
- Автообновления нет: новая версия ставится скачиванием установщика с GitHub Releases.
- Публичного репозитория и лендинга пока нет; после открытия репозитория они станут
  основным каналом.

## Этап 1. Открытие и базовый канал (macOS + Linux)

1. Опубликовать репозиторий с `LICENSE`, `DCO`, `CONTRIBUTING.md` и `SECURITY.md`.
2. Включить GitHub Releases как единственный источник установщиков: тег `v*`, в
   описании — изменения, в ассеты — только `.dmg`, `.deb` и `.AppImage`, рядом —
   `SHA256SUMS`.
3. В README и в описании релиза явно указать, что сборки неподписанные, и дать
   инструкцию для текущей версии macOS.
4. Добавить аттестации сборок (`actions/attest-build-provenance`) и `SHA256SUMS`,
   чтобы пользователь мог проверить происхождение артефакта.
5. Завести цель спонсорства на Apple Developer Program ($99/год) — это первый
   юридический платёж, который снимает основное трение на macOS.

## Этап 2. Подпись и нотаризация macOS

Без Apple Developer Program нотаризация невозможна, поэтому шаг выполняется после
сбора средств.

1. Оформить Apple Developer Program и Developer ID Application сертификат.
2. Хранить сертификат и пароли только в секретах GitHub Actions: `APPLE_CERTIFICATE`,
   `APPLE_CERTIFICATE_PASSWORD`, `APPLE_SIGNING_IDENTITY`, `APPLE_ID`,
   `APPLE_PASSWORD` (app-specific password), `APPLE_TEAM_ID`.
3. Включить hardened runtime и нотаризацию в `bundle.macOS`, проверить
   `spctl -a -vv` и `codesign --verify --deep --strict` на собранном `.app`.
4. Убрать из README обходы Gatekeeper и оставить обычную установку из `.dmg`.
5. До появления сертификата допустима ad-hoc подпись (`"signingIdentity": "-"`) —
   это требование Apple Silicon, но не замена Developer ID.
6. Mac App Store не планируется: sandbox и правила магазина конфликтуют с
   текущими файловыми сценариями, а аккаунт стоит тех же $99.

## Этап 3. Каналы Linux

1. `.deb` и `.AppImage` остаются прямыми артефактами релиза.
2. AUR: PKGBUILD, собирающий из исходников тега, и запись в AUR. Нужен мейнтейнер,
   готовый обновлять пакет под релизы.
3. Flathub — после стабилизации: нужны AppStream metainfo, скриншоты, иконки,
   лицензия, описание sandbox-разрешений и прохождение ревью Flathub. Tauri-приложение
   упаковывается, но доступ к произвольным путям придётся описать через portals.
4. Snap — только при явном запросе пользователей.

## Этап 4. Автообновление

1. Подключить `tauri-plugin-updater`: `bundle.createUpdaterArtifacts = true`,
   публичный ключ в `tauri.conf.json`, приватный — в секретах CI.
2. Ключи Tauri (minisign) генерируются бесплатно: `npx tauri signer generate`.
   Потеря приватного ключа навсегда лишает возможности обновлять установленные копии.
3. Публиковать `latest.json` в GitHub Releases и указать его как endpoint.
4. Проверить обновление на неподписанной сборке macOS: подпись Tauri подтверждает
   целостность канала, но не заменяет подпись Apple; после нотаризации повторить тест.
5. Предусмотреть откат: версия в `latest.json` не понижается, сломанный релиз
   снимается, пользователю предлагается ручная переустановка.

## Этап 5. Витрина и обратная связь

1. Лендинг на GitHub Pages: что это, форматы, ограничения, приватность, скриншоты
   (готовые — в `docs/screenshots/`), кнопка скачивания и ссылка на
   `THIRD_PARTY_NOTICES.md`.
2. Страница релизов с понятными именами файлов и инструкцией по проверке `SHA256SUMS`.
3. Шаблон бага уже требует версию, ОС и формат файла; при росте — opt-in краш-репорты
   с политикой приватности.
4. Метрики без телеметрии: число скачиваний релизов, звёзды, issues, отзывы в
   каналах. Телеметрию вводить только с явным согласием.

## Чего не делаем сейчас

- Windows-каналы (winget, Microsoft Store) — после macOS и Linux.
- Платную подписку и закрытые серверные функции — отдельный репозиторий, когда
  появится спрос.
- Двойное лицензирование и CLA — проект остаётся на MIT и DCO.
