# Wordlite

Кроссплатформенный (macOS, Linux, Windows) редактор документов — аналог Word для
повседневных задач. Ядро на Rust, интерфейс на React и TipTap, оболочка на Tauri 2.

## Статус

Работают окно приложения, WYSIWYG-редактор, несколько документов во вкладках, открытие
и сохранение TXT и Markdown, вставка изображений и таблиц, печать, нативные диалоги,
защита от потери изменений и валидация модели документа. DOCX, RTF, HTML и экспорт
PDF — в разработке.

Реализовано сейчас:
- редактор TipTap: заголовки, bold/italic, списки, цитаты, блоки кода, таблицы,
  изображения, undo/redo;
- вкладки документов: отдельный редактор и история undo/redo на вкладку, кнопка «+»,
  закрытие, маркер несохранённых изменений;
- открытие нескольких файлов за раз; уже открытый файл не дублируется;
- липкая шапка с вкладками «Главная» и «Вставка»;
- вкладка «Вставка»: изображение, таблица с выбором размера до 6×6, разделитель
  страниц;
- панель управления таблицей при курсоре в ней: +/− столбцы и строки, удаление;
- разрыв страницы, который сохраняется в Markdown маркером `<!-- pagebreak -->`;
- открытие и сохранение `.txt` и `.md` / `.markdown` через Rust-конвертеры;
- файловые действия в нативном меню приложения с акселераторами;
- печать текущего документа через системный диалог (`Cmd/Ctrl+P`);
- имя активного файла и признак несохранённых изменений в заголовке окна;
- подтверждение при закрытии изменённой вкладки, окна и выходе (Cmd+Q, Dock);
- предупреждения о неподдержанной разметке и потерях при сохранении в TXT;
- счётчик слов и индикатор версии Rust-ядра;
- светлая и тёмная темы (следует системной);
- модель документа на базе ProseMirror JSON с валидацией и лимитами;
- CI: проверки на Ubuntu, сборка бандлов на трёх ОС.

Планируется:
- шрифты, размеры, цвета, выравнивание, отступы и интервалы;
- объединение ячеек, изображения как assets;
- колонтитулы, гиперссылки в редакторе;
- поиск и замена, автосохранение и восстановление сессии;
- импорт и экспорт DOCX, RTF, HTML;
- экспорт PDF с постраничной вёрсткой (A4/Letter, поля, ориентация);
- установщики `.dmg`, `.msi`, `.AppImage`/`.deb`.

## Меню

Файловые действия находятся в системном меню (на macOS — строка меню сверху экрана,
на Linux и Windows — меню в верхней части окна):

- **Wordlite** — «О Wordlite», «Скрыть», «Выйти из Wordlite» (`Cmd+Q` с защитой
  несохранённых изменений);
- **Файл** — «Новый» (`Cmd+N`), «Открыть…» (`Cmd+O`), «Сохранить» (`Cmd+S`),
  «Сохранить как…» (`Cmd+Shift+S`), «Печать…» (`Cmd+P`), «Закрыть документ»
  (`Cmd+W`), «Закрыть окно» (`Cmd+Shift+W`);
- **Окно** — «Свернуть», «Масштаб».

Выход через меню, Dock, закрытие изменённой вкладки или окна требует подтверждения.
На Windows и Linux вместо `Cmd` используется `Ctrl`.

## Форматы

| Формат | Импорт | Экспорт | Примечание |
|---|---|---|---|
| TXT | да | да | UTF-8, абзацы разделяются пустой строкой, одиночный перенос — `hardBreak` |
| Markdown (GFM) | да | да | заголовки, списки, код, цитаты, ссылки, изображения, таблицы; разрыв страницы — `<!-- pagebreak -->` |
| DOCX | план | план | следующий этап |
| RTF | план | план | после DOCX |
| HTML | план | план | с санитизацией |
| PDF | — | план | вёрстка через Typst |

Ограничения текущей итерации:
- поддерживается только UTF-8; другие кодировки возвращают понятную ошибку;
- вставленные изображения хранятся как `data:` URL (лимит 15 МБ, форматы png/jpg/
  jpeg/gif/webp, без SVG); это увеличивает размер Markdown, отдельные assets — позже;
- таблица вставляется размером до 6×6 с заголовком; объединение ячеек — позже;
- разрыв страницы сохраняется в Markdown маркером `<!-- pagebreak -->`; в TXT он
  выводится как линия и не восстанавливается при открытии;
- task lists, сноски и сырой HTML в Markdown пропускаются с предупреждением;
- сложные конструкции DOCX/RTF будут поддерживаться частично.

## Модель документа

Источник истины — ProseMirror JSON (схема v1, корневой узел `doc`). Rust-ядро
проверяет структуру: тип корня, текстовые узлы без детей, лимиты глубины (256) и числа
узлов (1 000 000). Атрибуты узлов и марок хранятся как JSON, поэтому схема расширяется
без изменения Rust-типов.

Файловые операции:
- чтение — UTF-8 с BOM, лимит 50 МБ;
- запись — атомарная (временный файл и rename), исходный файл не повреждается при
  ошибке;
- формат определяется по расширению, неподдерживаемое расширение возвращает
  `unsupported_format`;
- ошибки IPC имеют единый вид `{ code, message }`.

## Ограничения

- Вкладки документов живут в памяти: после перезапуска приложения сессия не
  восстанавливается. «Сохранить все» и drag&drop файлов во вкладки — позже.
- Пагинация в редакторе приблизительная: документ отображается непрерывным потоком в
  A4-рамке. Печать использует встроенный диалог печати webview и CSS `@media print`
  без колонтитулов и точной вёрстки; точная постраничная вёрстка — при экспорте PDF.
- Поддержка DOCX/RTF будет частичной: сложные конструкции Word пропускаются с
  предупреждением.
- ODT, импорт PDF, сноски, оглавление, рецензирование и совместное редактирование
  в текущий объём не входят.
